# VoltWorks — 전기 회로 작업대

VoltWorks는 중·고등학생(초6~고2)이 전지, 전구, 저항, 스위치, 전류계, 전압계를 작업대에 놓고
직렬·병렬 회로를 직접 시험하는 정적 교육용 웹 앱입니다. 회로는 브라우저 안에서 수정 노드 해석
(MNA)으로 계산하며, 빌드된 앱은 서버·API·런타임 AI 없이 동작합니다.

**라이브:** https://wbmaker2.github.io/voltworks/

## 주요 기능

- 전지 1.5 V / 3 V / 9 V, 전구(3 V · 0.6 W), 고정 저항 6종, 스위치, 이상적 전류계·전압계
- 격자 기반 회로 편집: 배치, 이동, 회전, 삭제, 전선 연결, 경유점, 교차·접합 규칙, 실행 취소/다시 실행
- MNA 솔버: 직렬·병렬·전압 분배, 전류 보존, 등가 저항, 전력 계산, 결정론적 결과
- 단락·열린 회로·부동 부품·계측기 오결선 경고와 해당 부품/전선 강조
- 전류 입자 애니메이션, 전구 밝기(P = I²R), 전압·전류·전력·저항 계측 패널
- 2D 회로도와 Three.js 기반 3D 탁상 보기
- 6개 미션: 예측 → 제작·측정 → 설명 → 정리, 로컬 진행 저장, 미션별 점수
- 교사용: 정답 공개, 진행 초기화, 회로 도해가 포함된 학습지 인쇄
- PWA: 설치 및 첫 로드 후 오프라인 사용
- 데스크톱 3열, 태블릿 드로어, 휴대폰 하단 시트 레이아웃
- 키보드 경로, 화면 읽기용 회로 요약, 경고 라이브 영역, 모션 줄이기

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 엽니다.

### 스크립트

| 명령                | 설명                                                |
| ------------------- | --------------------------------------------------- |
| `npm run dev`       | 개발 서버                                           |

## 사용법

1. 왼쪽 **부품함**에서 부품을 고른 뒤 작업대를 클릭합니다. 태블릿·휴대폰에서는 부품/측정/미션
   하단 시트를 사용합니다.
2. 부품의 **단자**를 클릭하고 빈 격자를 거쳐 다른 단자를 클릭하면 전선이 이어집니다.
3. 스위치 본체를 클릭하면 열고 닫을 수 있습니다. 선택한 부품은 `R`로 회전하고 `Delete`로 지웁니다.
4. 오른쪽 **측정 패널**에서 선택한 부품과 회로 전체의 값을 확인합니다. 경고 카드를 누르면 문제
   부품이나 전선이 선택됩니다.
5. **미션** 화면에서 여섯 개의 미션을 시작합니다. 예측을 먼저 고르고, 회로를 만든 뒤 **측정하기**를
   누르고, 측정값을 근거로 설명을 고릅니다.

### 키보드

`Tab`으로 이동, `Enter`로 놓기/연결, 화살표로 이동, `N` 다음 부품(`Shift+N` 이전),
`W` 전선 시작(`Shift+W` 반대 단자), `R` 회전, `Delete` 삭제, `Esc` 취소.

## 계산 모델

- 전선 0 Ω, 전류계 0 Ω(0 V 전압원), 전압계 1 GΩ, 닫힌 스위치 1 mΩ, 전구는 일정 저항 15 Ω
- 전지와 전류계는 이상적 전압원으로, 나머지는 저항으로 계산합니다.
- 단락은 전지 양극 사이 등가 저항이 0.05 Ω 미만이거나 전류가 10 A를 넘을 때 경고합니다.
- 계산은 실수 부동소수점 MNA이며, 같은 회로와 값에는 같은 결과를 냅니다.
- **교육용 저전압 모델입니다.** 실제 배선의 안전을 보증하지 않으며, 실제 전지로 단락 실험을
  재현하지 마세요.

## 구조

```text
src/
  app/        앱 셸, 상태 저장소, 라우팅, 동작 연결
  circuit/    타입, 기하, 넷리스트, MNA, 검증, 전력, 단위
  editor/     격자, 배치, 전선, 히트 테스트, 실행 취소/다시 실행
  render/     2D 캔버스, 전류 흐름, 3D 탁상, 학습지 미리보기
  features/   측정 패널, 미션, 교사용
  data/       부품 목록, 미션, 예제 회로
  storage/    localStorage 진행·회로 스냅샷
  ui/         공통 UI 조각과 아이콘
  styles/     디자인 토큰과 반응형 스타일
tests/
  unit/       솔버·검증·미션 단위 테스트
  e2e/        Playwright 상호작용·접근성·PWA 테스트
```

## 테스트

- Vitest 단위 테스트: 솔버 부호 규약, 직렬/병렬/분배, 계측기, 단락/부동/열린 회로, 전선 교차와
  T 접합, 미션 프리셋 목표, 단위 포맷
- Playwright: 빈 작업대에서 회로 만들기, 직렬/병렬 측정, 전구 밝기, 계측기 배치, 단락 수정,
  미션 완료, 키보드만으로 미션 완료, 교사용 정답/초기화, 세 가지 화면 너비, 오프라인 재로드
- `@axe-core/playwright`로 WCAG 2 A/AA 자동 검사

## 배포

`npm run build`가 만드는 `dist/`를 GitHub Pages, Cloudflare Pages, Netlify 등 정적 호스팅에
올리면 됩니다. `vite.config.ts`의 `base: './'` 덕분에 하위 경로에서도 동작합니다.

이 저장소는 `.github/workflows/deploy.yml`을 통해 `main` 브랜치에 푸시할 때마다 린트·단위
테스트·빌드를 거쳐 GitHub Pages로 자동 배포됩니다. 서버, 데이터베이스, API 키, 런타임 네트워크
호출은 없습니다.
