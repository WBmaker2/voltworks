# VoltWorks 업데이트 내역

## 2026-10-30

### 추가

- VoltWorks 전기 회로 작업대 첫 구현.
- 전지(1.5V·3V·9V), 전구, 저항 6종, 스위치, 전류계, 전압계 부품과 격자 작업대를 추가했습니다.
- 직접 전선을 잇고, 경유점을 만들고, 부품을 옮기고 돌리고 지우는 편집 기능을 넣었습니다.
- 회로를 실제로 계산하는 MNA 솔버와 직렬·병렬·전압 분배 계산을 넣었습니다.
- 열린 회로, 단락, 연결되지 않은 부품, 전류계/전압계 오결선 경고를 넣었습니다.
- 전류 입자 애니메이션, 전구 밝기, 전압·전류·전력 계측 패널을 넣었습니다.
- 2D 회로도와 3D 탁상 보기를 넣었습니다. 3D는 2D에서 계산한 값만 보여 줍니다.
- 예측 → 제작·측정 → 설명 순서로 진행하는 미션 6개를 넣었습니다.
- 미션 진행과 점수를 이 기기에 저장하고, 교사용 화면에서 정답 공개·진행 초기화·학습지 인쇄를 할 수 있게 했습니다.
- 교사용 정답 영역에서 목표 회로 도해를 펼쳐 볼 수 있게 했습니다.
- 화면 읽기용 회로 요약에 전선 연결 정보를 넣었습니다.
- 첫 로드 뒤 오프라인에서도 열리는 PWA와 앱 아이콘을 넣었습니다.
- 데스크톱 3열, 태블릿 드로어, 휴대폰 하단 시트 화면을 넣었습니다.
- 키보드만으로 미션을 완료하는 경로, 화면 읽기용 회로 요약, 경고 읽어 주기, 모션 줄이기를 넣었습니다.
- `main` 브랜치에 푸시하면 린트·단위 테스트·빌드를 거쳐 GitHub Pages로 자동 배포되는 워크플로를 추가했습니다.
- 배포 주소: https://wbmaker2.github.io/voltworks/

### 수정

- 저항 값이 100Ω·220Ω·470Ω일 때 앞자리 0이 잘려 1Ω·22Ω·47Ω로 보이던 표시 문제를 고쳤습니다.
- 3D 보기에서 돌아왔을 때 2D 화면이 엉뚱한 위치로 확대되던 문제를 고쳤습니다.
- 전압 분배 예제의 복귀 전선이 전압계 단자를 지나가며 회로를 단락시키던 문제를 고쳤습니다.
- 병렬 회로 미션에서 빠진 전선을 스위치 단자에서 쉽게 시작할 수 있도록 예제 회로를 다듬었습니다.
- 다크 테마에서 제목과 큰 숫자가 어두운 배경에 묻히던 문제를 고쳤습니다.
- 휴대폰 상단 메뉴가 세로로 줄바꿈되던 문제와 아이콘 버튼의 이름이 사라지던 접근성 문제를 고쳤습니다.
- 버튼·작은 글자의 색 대비를 WCAG AA에 맞게 조정했습니다.
- 전구 밝기·점수·경고 색이 색만으로 구분되지 않도록 아이콘·글자·테두리를 함께 사용했습니다.

### 검증

- 단위 테스트 30개 통과: 솔버, 전선 교차/T 접합, 계측기 경고, 미션 프리셋, 단위 표시.
- Playwright 테스트 18개 통과(휴대폰·데스크톱): 회로 만들기, 직렬/병렬, 단락 수정, 미션 완료,
  키보드만으로 미션 완료, 교사용 초기화, 오프라인 재로드, 세 가지 화면 너비.
- axe-core WCAG 2 A/AA 자동 검사에서 위반 0건.
- `npm run build` 성공, 초기 JS gzip 약 189KB.
